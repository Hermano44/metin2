# Metin2

Metin2 tarzında, klasik MMORPG deneyimini yeniden oluşturmayı hedefleyen ücretsiz bir oyun projesi.

## Hedefler
- 3D açık dünya
- Üçüncü şahıs karakter kontrolü
- Savaş ve yetenek sistemi
- Canavarlar ve bosslar
- Görevler ve NPC'ler
- Envanter ve ekipman
- Seviye ve eşya geliştirme
- Çok oyunculu çevrimiçi dünya

## Teknoloji
- Three.js
- JavaScript
- WebGL
- GitHub

## Geliştirme İlkesi
Proje ücretsiz araçlar ve açık kaynak teknolojiler kullanılarak geliştirilecektir.
